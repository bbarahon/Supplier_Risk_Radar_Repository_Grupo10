# Supplier-Risk-Radar_Repository
Sistema que lee noticias a diario y avisa al equipo de compras de Helixa Pharmaceuticals (farmacéutica ficticia con 40 proveedores) de los eventos que amenazan su suministro. Para cada artículo decide si es un riesgo, si es urgente según la dependencia de Helixa del proveedor, y qué proveedores se ven afectados.
